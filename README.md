# Excel-Sales-Dashboard
Interactive Excel dashboard for analyzing sales, profit, regional performance and customer performance.


## Project Overview

This project uses an Excel sales dataset to transform raw order-level data into an interactive business dashboard. The dashboard provides a clear view of key sales and profit metrics and helps identify patterns across product categories, regions, customers, and time.

## Dataset

The dataset contains **1,952 sales records** with **25 columns**, including:

- Order ID and Row ID
- Order Date and Ship Date
- Customer ID and Customer Name
- Customer Segment
- Product Category and Product Sub-Category
- Product Name
- Region, State, City and Country
- Sales
- Profit
- Quantity Ordered
- Discount
- Unit Price
- Shipping Cost
- Product Base Margin
- Ship Mode
- Order Priority

## Dashboard Features

The **Category Sheet** provides interactive analysis of sales performance by product category and related business metrics.

Key analysis includes:

- Total Sales
- Total Profit
- Quantity Sold
- Customer Analysis
- Product Category Performance
- Regional Sales Performance
- Sales and Profit Analysis
- Order and Customer Insights
- Interactive filtering using Excel slicers

## Key Categories

## Dashboard Structure

### Orders_Table
Contains the raw sales and order-level dataset used for analysis.

### Dashboard_PT
Contains the supporting Pivot Table calculations used for the dashboard.

### Category Sheet
Interactive dashboard for analyzing product category performance and sales-related insights.

### Region
Sheet dedicated to regional analysis.

### Customers
Sheet dedicated to customer-related analysis.

### About
Contains project information and dashboard details.
